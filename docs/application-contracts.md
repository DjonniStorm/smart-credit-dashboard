# Контракт конвейера заявки

Источник типов: `packages/contracts/src/application.ts`.

## Команды

`employeeActionSchema` — версиируемый контракт команд АРМ. Новые команды не
должны менять смысл существующих `approve`, `counter_offer`, `request_info`,
`reject`, `assign` и `rerun_check`.

Текущие дополнительные команды:

- `pause` / `resume` — временно остановить и продолжить рассмотрение;
- `block` — постоянная блокировка с причиной;
- `comment` — комментарий с видимостью `client`, `internal` или `handoff`;
- `handoff` — передача сотруднику с кратким резюме, проверенными фактами,
  открытыми вопросами, ожидаемыми документами и следующим шагом;
- `cancel` — отмена заявки до выдачи;
- `set_urgent` — включение или выключение срочного режима.

`applicationCommandSchema` — совместимое имя для интеграций, которым нужен
термин «команда». Оно ссылается на тот же discriminated union.

## Аудит

Каждый `ApplicationEvent` относится к заявке и содержит UTC-время, автора,
человеческое название и переход статуса. Новые записи могут дополнительно
указывать `kind`:

- `status_changed` — переход публичного статуса;
- `action` — действие сотрудника без смены статуса;
- `comment_added` — добавлен комментарий;
- `handoff` — создана передача;
- `hold` — заявка поставлена на паузу или блокировку.

`metadata` предназначен только для небольших индексируемых значений
(например, `assigneeId`, `reasonCode`, `visibility`). Сырые документы,
токены и полные payload внешних источников в audit event не записываются.

Старые события без `kind` и `metadata` остаются валидными: оба поля
необязательны. `Application.comments` и `Application.handoff` имеют значения
по умолчанию, поэтому старые fixtures без этих полей продолжают проходить
валидацию.

## Комментарии и handoff

`ApplicationComment.visibility` определяет аудиторию. Клиентские комментарии
можно показывать в кабинете, внутренние — только сотрудникам банка,
`handoff` — следующему ответственному и руководителю.

Handoff не заменяет историю событий: он хранит актуальный пакет передачи,
а событие с `kind: "handoff"` фиксирует факт и время передачи. Передача
должна содержать хотя бы `summary` и `nextStep`; остальные массивы могут быть
пустыми, если факты или вопросы отсутствуют.

## Обратная совместимость

- Не переиспользовать существующие значения `type` для другого поведения.
- Новые поля в ответах добавлять optional/default.
- Публичный статус и внутренний этап не смешивать: `Application.status` — для
  маршрута, `Application.stage` — для конвейера.
- Причины блокировки и отказа не передавать в `metadata` как свободный сырой
  текст, если для них уже есть enum-контракт.
