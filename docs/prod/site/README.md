# Сайт документации

Самостоятельный статический сайт на Rspress. Для разработки нужны Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Проверка production-сборки и локальный просмотр:

```bash
npm run build
npm run preview
```

Rspress складывает готовый сайт в `doc_build/`.

## Публикация в Vercel

Создайте отдельный Vercel Project для этого репозитория и задайте Root Directory `docs/prod/site`. `vercel.json` задаёт установку через `npm ci`, команду сборки и каталог `doc_build`. Игнорируемая команда пропускает сборку, если в коммите нет изменений внутри корня сайта.

Сайт не использует переменные окружения, серверные функции или API приложения.
