# Локальная разработка

Локальный контур поднимает те же роли, которые описаны в пользовательских разделах: Client Web, банковское АРМ, API и scoring. Для запуска нужны Node.js 24, pnpm 11.25.0, Python 3.12, `uv` и запущенный Docker. Команда scoring запускает `uv run --locked uvicorn`.

Из корня репозитория выполните:

```bash
pnpm install
pnpm dev
```

Команда `pnpm dev` запускает PostgreSQL в Docker и приложения через Turborepo. Основные адреса:

| Компонент | Адрес |
| --- | --- |
| Кабинет предпринимателя | `http://localhost:3000` |
| Банковское АРМ | `http://localhost:3001` |
| Swagger UI API | `http://localhost:4000/docs` |
| Scoring Swagger UI | `http://localhost:8000/docs` |

Опубликованные адреса для проверки интерфейсов и API:

- [Кабинет предпринимателя](https://sales.eegov.net/login)
- [Кабинет сотрудника банка](https://backoffice.sales.eegov.net/login)
- [Swagger API](https://api.sales.eegov.net/docs)

Для заполнения демонстрационных данных выполните `pnpm --filter api db:seed`. Команда идемпотентна. Чтобы остановить локальную PostgreSQL, используйте `pnpm db:down`.

## Запуск сайта документации

Сайт в `docs/prod/site` устанавливается и запускается отдельно:

```bash
cd docs/prod/site
npm ci
npm run dev
```

Ему не нужны Docker, API или зависимости pnpm workspace.
