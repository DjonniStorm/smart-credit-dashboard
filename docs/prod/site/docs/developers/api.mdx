# API

Интерфейсы обмениваются данными с API по HTTP. API проверяет сессию и полномочия пользователя, валидирует команды и возвращает актуальное состояние заявки. Клиентский интерфейс не меняет статус локально в обход ответа API.

## Контракт и документация

OpenAPI-документ строится из серверных контроллеров и схем. При локальном запуске Swagger UI доступен по адресу [`http://localhost:4000/docs`](http://localhost:4000/docs). Ссылка открывается только при запущенном API на той же машине.

АРМ использует сессию сотрудника. Действия с заявкой передают команду и ключ идемпотентности; сервер проверяет допустимость перехода и сохраняет его вместе с записью истории.

Этот сайт не зеркалирует OpenAPI-схему. Для актуальных путей, параметров и ответов используйте Swagger запущенной версии API.
