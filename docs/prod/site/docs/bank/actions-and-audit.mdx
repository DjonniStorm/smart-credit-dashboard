# Действия и история

Каждое действие сотрудника проходит через API и появляется в истории заявки. История показывает, кто изменил маршрут, с какой причиной и какие комментарии остались после решения. Повтор команды с тем же ключом идемпотентности не должен применяться второй раз.

[Открыть действия и историю](https://backoffice.sales.eegov.net/login)

В зависимости от заявки и роли сотрудник может назначить ответственного, запросить сведения, подтвердить или изменить рекомендацию, предложить другие условия, отказать, передать заявку, поставить её на паузу или повторить проверку источника.

Вкладка «История» и журнал показывают действия и комментарии. Клиентские комментарии доступны предпринимателю, внутренние заметки остаются в банковском АРМ. Для решений, расходящихся с рекомендацией, нужна причина.
