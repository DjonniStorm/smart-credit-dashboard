# Проверка заявки

Карточка проверки собирает сведения о компании, источники, документы, расхождения и рекомендацию scoring в одном рабочем месте. Сотрудник сопоставляет факты с ограничениями продукта и запрашивает уточнение, если данных недостаточно.

[Открыть проверку заявки](https://backoffice.sales.eegov.net/login)

## Рекомендация и решение

Scoring формирует оценку и рекомендацию. Сотрудник может подтвердить рекомендацию или принять другое решение в рамках своих полномочий. Если решение расходится с рекомендацией, система требует указать причину.

Автоматические расчёты помогают разобрать заявку, но не подменяют решение уполномоченного сотрудника.

## Передача и пауза

Если требуется участие другого сотрудника, передайте ему проверенные факты, открытые вопросы и следующий шаг. При паузе или блокировке укажите причину. После снятия паузы система продолжит процесс с сохранённым контекстом.
