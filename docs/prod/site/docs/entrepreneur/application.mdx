# Создание заявки

Перед отправкой заявки выберите цель финансирования и кредитный продукт, задайте сумму и срок, заполните финансовые сведения и добавьте документы. Система сохраняет незавершённую форму как черновик.

## Перед отправкой

1. Укажите, на что нужны средства.
2. Выберите подходящий продукт и параметры финансирования.
3. Заполните сведения о бизнесе и денежных потоках.
4. Приложите документы, которые подтверждают указанные данные.
5. Проверьте сводку и отправьте заявку.

Песочница условий и симулятор переговоров помогают сравнить варианты, но сами по себе не создают заявку и не означают одобрение. Решение принимает банк после проверок.

## После отправки

Дорожная карта показывает завершённые этапы, текущий этап, ожидаемого участника и возможный следующий шаг. Служебные стадии обработки система переводит в понятные статусы кабинета.

Если нужно продолжить позже, откройте черновик из списка заявок. Удаление черновика не отменяет уже отправленную заявку.
