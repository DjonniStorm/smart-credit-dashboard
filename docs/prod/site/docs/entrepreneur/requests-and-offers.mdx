# Запросы банка и предложения

Этот раздел показывает две ситуации после проверки: банку не хватает сведений или он предлагает другие условия. В первом случае клиент отвечает на запрос, во втором сравнивает предложение с исходной заявкой.

## Ответ на запрос

Прочитайте, какие сведения нужно подтвердить. Напишите пояснение и приложите документ, если это требуется. После отправки ответа дождитесь обновления статуса: дальнейший этап запускает система.

Если источник данных временно недоступен, это может привести к ручной проверке. Недоступность источника сама по себе не означает отказ.

## Встречное предложение

Банк может предложить другие сумму, срок или продукт. Сравните новые условия с первоначальным запросом. Принятие или отказ требуют подтверждения в интерфейсе.

Изменить предложенные банком параметры как исходный запрос нельзя. Песочница показывает ориентир и не заменяет решение банка.
