# Кабинет предпринимателя

Кабинет помогает подготовить заявку, следить за её состоянием и отвечать на запросы банка. Для входа выберите одну из показанных учётных записей. Пароль не требуется.

## Основные разделы

- **Заявки**: активные заявки, черновики и действия, которые ожидаются от вас.
- **Подобрать кредит**: выбор цели и продукта, расчёт условий и создание заявки.
- **Компания**: профиль компании и сведения по источникам.
- **Документы**: файлы, приложенные к заявкам и ответам банку.
- **Отчёты**: сводные сведения клиентского кабинета, если они доступны в текущем демо-сценарии.

## Как читать состояние заявки

Карточка показывает текущий статус и следующий шаг. Если банк проверяет сведения, действий от вас может не требоваться. При запросе уточнения ответьте на вопрос и, если нужно, приложите документ. Предложение банка можно сравнить с исходными условиями и принять либо отклонить.

Статус отображает текущий этап обработки заявки и действие, которое ожидается следующим.
