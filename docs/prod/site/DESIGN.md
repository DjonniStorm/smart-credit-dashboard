# Направление сайта

- Аудитория: предприниматели, сотрудники банка и разработчики проекта.
- Характер: сдержанный финтех, точный и понятный; акцентный цвет взят из интерфейса продукта.
- Палитра: нейтральные поверхности, тёмный текст, один красный акцент для текущего раздела и основных действий.
- Типографика: системный шрифт сохраняет привычную читаемость интерфейса и не добавляет внешние ресурсы.
- Композиция: три равноправных входа в документацию соответствуют трём аудиториям; внутри разделы группируются по реальным задачам.
- Движение: ENERGY 2 / RHYTHM 2 / MOTION 1. Анимация ограничена стандартными интерактивными состояниями темы.
