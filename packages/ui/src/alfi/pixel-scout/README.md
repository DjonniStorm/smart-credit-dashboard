# Альфи: Pixel Scout

Десять вариантов одного маскота на сетке 128 × 128. В сравнении с первым эскизом сетка стала вдвое мельче: появились оттенки куртки, блики, ремни, обувь, оборудование и предмет в руках. Общими остаются красный головной убор, белое лицо, тёмный контур и короткий походный силуэт.

| Файл | Вариант | Основная деталь |
| --- | --- | --- |
| `01-classic.svg` | классический | кепка, рюкзак и карта |
| `02-hooded.svg` | капюшон | глубокий капюшон и компас |
| `03-analyst.svg` | аналитик | гарнитура и планшет |
| `04-courier.svg` | курьер | козырёк, сумка и конверт |
| `05-visor.svg` | визор | сканирующая маска и модули |
| `06-ranger.svg` | рейнджер | широкая шляпа и бинокль |
| `07-formal.svg` | деловой | пиджак и папка решения |
| `08-technician.svg` | техник | наушники, пояс и тестер |
| `09-night.svg` | ночной | фонарь и светящаяся карта |
| `10-flagbearer.svg` | знаменосец | округлый шлем и маршрутный флаг |

Палитра: `#EF3124`, `#C91D16`, `#171717`, `#505759`, `#D9D9D6`, `#FFFFFF`. SVG используют `shape-rendering="crispEdges"` и сохраняют прозрачный фон.

Открыть [`preview.html`](preview.html) для сравнения на светлом и тёмном фоне в размерах 192, 64 и 32 пикселя.
