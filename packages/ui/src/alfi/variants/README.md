# Альфи — десять новых направлений

Персонажи на выбор, до разработки семи рабочих состояний. Общая связь с продуктом — помощь с маршрутом заявки и объяснение следующего шага. Ни один вариант не использует логотип банка.

Цветовая основа взята из [официального обзора фирменного стиля Альфа-Банка](https://alfabank.servicecdn.ru/site-upload/c7/97/837/alfa-brandbook.pdf): красный `#EF3124`, чёрный `#000000`, тёмно-серый `#505759`, светло-серый `#D9D9D6`. Красный обязателен; банк разрешает дополнять палитру, если используются минимум два основных цвета. В эскизах чёрный смягчён до `#171717`, а белый служит фоном и лицом персонажа. Вариант `05` использует светло-красный блик.

Открыть [`preview.html`](preview.html), чтобы сравнить все десять на светлом и тёмном фоне и в размерах 176, 64 и 32 пикселя. Это эскизы для выбора направления; окончательные пропорции, мимику и семь поз стоит отрабатывать после выбора персонажа.

Пиксельное направление продолжено отдельной серией: [`../pixel-scout/README.md`](../pixel-scout/README.md). Там находятся десять более детализированных вариантов одного Альфи-скаута.
