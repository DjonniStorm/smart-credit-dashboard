# @repo/ui

Дизайн-система кабинета: тема Mantine, пресеты Motion, общие компоненты.
Подключение: `UiProvider` из `@repo/ui/provider`, `density="compact"` для АРМ.

## Цвет

Основа своя: чернила для текста и второстепенных кнопок, тёплый бумажный фон,
Golos Text. Фирменный красный банка (ответ организаторов №18 разрешает фирменные
цвета) работает только как акцент действия.

### Когда красный

- Основная кнопка экрана. `<Button>` без `color` уже красная.
- Активный пункт навигации (`NavLink`): красный текст на `--kk-brand-soft`.
- Текущий этап в `StageRail`, выбранная строка в `QueueTable`.
- Кольцо фокуса и подчёркивание активной вкладки (`Tabs`) берутся из primary.
- Выделенный столбик графика: `--kk-brand-bright`.

### Когда не красный

- Текст, ссылки, второстепенные кнопки: чернила. Ссылки отличаются подчёркиванием.
- Статусы. «Нужно действие» остаётся янтарным (`tone="action"`, `Marker`,
  этап `action` в `StageRail`): это «ход за вами», а не кнопка.
- Ошибки и отказ. `danger` темнее бренда, всегда с иконкой (`IconCircleX`,
  `IconAlertCircle`) и подписью, и никогда не бывает заливкой кнопки.
- Скоринг и бейджи без тона. `color="primary"` по-прежнему чернила, а `subtle`
  и `light` без цвета остаются нейтральными.

Одна красная кнопка на экран. Если просится вторая, она `variant="default"`.

### Контрасты

WCAG 2.x. Текст: не ниже 4.5:1. Полосы и границы элементов: не ниже 3:1.

| Пара                   | Контраст | Где                            |
| ---------------------- | -------- | ------------------------------ |
| `#ffffff` на `#d62b1f` | 4.97     | текст кнопки                   |
| `#ffffff` на `#bd2418` | 6.12     | текст кнопки при наведении     |
| `#ffffff` на `#ef3124` | 4.09     | поэтому `#ef3124` не под текст |
| `#d62b1f` на `#f6f4ef` | 4.52     | красный текст на бумаге        |
| `#d62b1f` на `#ffffff` | 4.97     | красный текст на карточке      |
| `#d62b1f` на `#fff3f2` | 4.58     | активный пункт меню            |
| `#d62b1f` на `#eceae3` | 4.13     | текущий этап на дорожке        |

| `#ff6b5e` на `#121314` | 6.66     | красный текст, тёмная          |

Ошибка и бренд различаются светлотой (6.57 против 4.97 на белом), иконкой и

Меняете значение в `src/theme.ts`, обновите эту таблицу.
