# @repo/ui

Дизайн-система кабинета: тема Mantine, пресеты Motion, общие компоненты.
Подключение: `UiProvider` из `@repo/ui/provider`, `density="compact"` для АРМ.

## Цвет

Тема по макетам `docs/design/business.jpg` и `docs/design/manager.jpg`: холодный
светло-серый фон, белые карточки, тонкие линии, Golos Text. Полное описание каркаса
и компонентов в дизайн-системе «Кредитный конвейер»
(https://claude.ai/artifact/F5x5rKNN1oZhTFqDoTHDUa). Фирменный красный банка (ответ
организаторов №18 разрешает фирменные цвета) работает только как акцент действия.

### Когда красный

- Основная кнопка экрана. `<Button>` без `color` уже красная.
- Активный пункт навигации (`NavLink`): красный текст на `--kk-brand-soft`.
- Текущий этап в `StageRail`, выбранная строка в `QueueTable`.
- Кольцо фокуса и подчёркивание активной вкладки (`Tabs`) берутся из primary.
- Выделенный столбик графика: `--kk-brand-bright`.

### Когда не красный

- Текст, ссылки, второстепенные кнопки: чернила. Ссылки отличаются подчёркиванием.
- Статусы. «Нужно действие» остаётся янтарным (`tone="action"`, `Marker`,
  этап `action` в `StageRail`): это «ход за вами», а не кнопка.
- Ошибки и отказ. `danger` темнее бренда, всегда с иконкой (`IconCircleX`,
  `IconAlertCircle`) и подписью, и никогда не бывает заливкой кнопки.
- Скоринг и бейджи без тона. `color="primary"` по-прежнему чернила, а `subtle`
  и `light` без цвета остаются нейтральными.

Одна красная кнопка на экран. Если просится вторая, она `variant="default"`.

## Альфи

`Alfi` — общий компонент помощника для кабинета клиента и банковского АРМ.
Пиксельные варианты находятся в `src/alfi/pixel-scout/`. Семь рабочих состояний
имеют отдельные SVG в `src/alfi/pixel-scout/states/` и выбираются автоматически:

```tsx
import { Alfi, AlfiState } from "@repo/ui/alfi";

<Alfi
  state={AlfiState.Checking}
  assetBasePath="/alfi/pixel-scout/states"
  size={96}
/>
```

Приложение может передать `src`, если ему нужен специальный SVG. Компонент
добавляет доступное описание, поддерживает `prefers-reduced-motion` и показывает
геометричный fallback, если ассет недоступен.

### Уведомления Альфи

`alfi` использует уже подключённый в приложении Mantine `<Notifications />`, но
добавляет персонажа и состояние к каждому уведомлению:

```tsx
import { alfi, AlfiOperation } from "@repo/ui/alfi";

const id = alfi.show({
  operation: AlfiOperation.NeedsInfo,
  message: "Проверьте банковскую выписку",
  raw: "исходная строка для будущей обработки",
  autoClose: 5000,
  withBorder: true,
});

alfi.update({
  id,
  operation: AlfiOperation.ActionCompleted,
  message: "Ответ сохранён",
});
```

`operation` обязателен и выбирает состояние по умолчанию. Параметр `state`
переопределяет его для специальных случаев. `message` — готовый текст для
пользователя, а `raw?: string` хранится отдельно и никогда не выводится.
Доступны `show`, `hide`, `update` и `clean`.

Для типовых состояний доступны короткие helpers:

```tsx
alfi.showNeedsInfo("Проверьте банковскую выписку", {
  raw: "statement_missing",
});
alfi.showOfferReady("Условия готовы", { autoClose: 5000 });
alfi.showAttention("Нужна ручная проверка", { withBorder: true });
```

Для Next-приложений стандартные SVG должны быть опубликованы в
`public/alfi/pixel-scout/states/`. В этом репозитории одинаковые наборы лежат в
`apps/client/public` и `apps/backoffice/public`.
